= Scale and Certify Agentic Systems
:navtitle: Welcome

== Continue the Same Workload

This 501 experience scales the evidence-backed multi-agent workload previously
built at 301 and operated at 401. You receive one assigned OpenShift namespace.
You do not provision multiple Launchpad participant environments in this lab.

Your goal is to discover the largest workload profile that preserves evidence
quality, deterministic policy, safe human authority, and acceptable Intel Xeon
inference behavior.

== Draft Truth Boundary

This is reviewable content, not an orderable lab. The baseline, sustained, and
pressure contracts and the 30-case evaluation set exist. Live workload
execution, correlated OpenTelemetry, approved Intel CPU telemetry, quality
scoring, and safe fault drivers are not deployed yet.

IMPORTANT: Never present planned thresholds, generated run plans, or supplied
examples as live results. A completed 501 lab accepts only measurements marked
`LIVE` from approved sources.

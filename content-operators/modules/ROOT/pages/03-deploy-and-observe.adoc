= Deploy and Observe a Workload
:navtitle: Deploy and Observe

Deploy a small OpenShift workload, expose it with a Route, and inspect it using standard Red Hat operational workflows.

== Deploy

[source,bash,role=execute,subs=attributes+]
----
oc create deployment hello --image=quay.io/openshifttest/hello-openshift:1.2.0 \
  -n {namespace}
oc expose deployment hello --port=8080 -n {namespace}
oc expose service hello -n {namespace}
oc rollout status deployment/hello -n {namespace} --timeout=120s
----

== Observe

[source,bash,role=execute,subs=attributes+]
----
oc get deployment,pod,service,route -n {namespace}
oc logs deployment/hello -n {namespace} --tail=20
HELLO_URL="http://$(oc get route hello -n {namespace} -o jsonpath='{.spec.host}')"
curl --fail --silent --show-error "$HELLO_URL"
----

Confirm that `curl` prints `Hello OpenShift!`. Then open *Topology* in the OpenShift Console and select `{namespace}`. Confirm the Deployment, Pod, Service, and Route are connected and healthy.

== Clean up the exercise

[source,bash,role=execute,subs=attributes+]
----
oc delete route,service,deployment hello -n {namespace}
----

Launchpad reclaims the entire seat namespace when the organizer ends the workshop, but removing exercise resources is part of the operational workflow.

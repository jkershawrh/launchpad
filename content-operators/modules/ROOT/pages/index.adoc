== Verify access

. Open the *Terminal* tab.
. Run:
+
[source,bash,role=execute,subs=attributes+]
----
oc project {namespace}
oc auth can-i create deployments.apps -n {namespace}
oc get pods -n {namespace}
----
. Confirm the authorization result is `yes` and the active project is your assigned namespace.

Open the link below in a separate browser tab, authenticate to {cluster_display_name}, and select your assigned namespace before changing any resource. The OpenShift Console cannot be embedded because its security policy blocks iframe access.

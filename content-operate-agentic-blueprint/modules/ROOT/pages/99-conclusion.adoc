== Clean Up the Learner Session

The policy override was removed and the deployment was restored in the prior
step. Close any remaining local port forwards and remove only the temporary
files created by this journey:

[source,bash,role="execute"]
----
kill "${MCP_FORWARD_PID:-}" "${PORT_FORWARD_PID:-}" 2>/dev/null || true
unset AGENT_AUTH_TOKEN BASELINE_MAX_TOKENS RESTORED_MAX_TOKENS
rm -f /tmp/agentic-401-*.json \
  /tmp/agentic-401-*.log \
  /tmp/agentic-401-baseline-max-tokens
test "$(oc get configmap workflow-policy --ignore-not-found)" = ""
oc rollout status deployment/multi-agent --timeout=5m
----

This learner cleanup does not delete the namespace, Showroom, routes, secrets,
or workload release. Those resources belong to Launchpad reclaim. Complete
certification separately proves that reclaim removes the whole seat and leaves
zero-residue; a participant must never perform that platform lifecycle action.

== What Remains Before Activation

This content is a 401 candidate, not an active catalog promise. Promotion
requires native journey correlation, certified OpenTelemetry collection,
independent service-outage recovery, approved Intel CPU telemetry, GitOps
drift proof, pipeline evaluation, immutable content provenance, and staged
one-, five-, and twenty-five-seat qualification. Kagenti integration is also
not deployed in this draft.

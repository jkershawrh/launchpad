== About This Lab

The Intel x Red Hat AI Launchpad showcases enterprise AI capabilities on Intel hardware running Red Hat OpenShift.
Every demo uses *real inference* — requests route through the LiteMaaS gateway to models running on Intel Gaudi 3 accelerators and Xeon 6 processors.

This lab demonstrates how Intel and Red Hat work together to deliver production-ready AI infrastructure.

== Architecture

All demos share a common architecture:

. *Demo Frontend* — React application filtered to show the relevant demo pages.
. *Inference Gateway* — FastAPI service that implements model routing policy.
. *LiteMaaS* — LiteLLM proxy providing unified OpenAI-compatible API across all models.
. *Intel Gaudi 3* — 24 accelerator cards serving models via KServe on OpenShift AI.
. *Intel Xeon 6* — CPU-based inference for embedding, classification, and small models.

Each tenant gets their own namespace, gateway instance, LiteLLM virtual key, and isolated resources.

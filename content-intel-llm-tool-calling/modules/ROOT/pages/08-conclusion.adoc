== Key Takeaways

=== Tool Calling Is a Protocol, Not Magic

The model produces structured JSON requests. Your code executes them. The model never runs tools directly. Understanding this separation is what lets you build, debug, and secure agentic AI systems.

=== The Model Decides, Your Code Executes

The dispatch pattern is simple: check for `tool_calls`, look up the function name in a dictionary, call it with the parsed arguments, return the result. The intelligence is in the model's decision-making. The engineering is in your dispatch loop, error handling, and guard rails.

=== Good Descriptions Drive Good Tool Selection

The `description` field in a tool definition is an instruction to the model. Vague descriptions lead to wrong tool calls. Specific descriptions with clear trigger conditions lead to reliable behavior.

=== CPU Inference Can Fit the Pattern

Tool calling's stop-and-go profile -- short outputs separated by tool execution waits -- can suit {intel_platform} CPUs. This lab does not compare CPU and GPU utilization or cost. Use destination placement evidence and measured workload data before making an efficiency or economic claim.


Launchpad Agent Swarm Demo.

Multi-agent parallel execution with coordination and result aggregation.

== What Gets Deployed

* *Keycloak user* -- SSO credentials for the demo
* *Tenant namespace* -- Isolated namespace with resource quotas
* *LiteLLM virtual key* -- Per-tenant API key for model-as-a-service inference
* *Demo frontend* -- Filtered to Agent Swarm pages (swarm)
* *Showroom* -- Interactive lab UI with terminal, console, and demo tabs

== Inference

All inference uses LiteMaaS backed by Intel Gaudi 3 accelerators via LiteLLM virtual keys.
